Android **0.19.0** (versionCode 35 → 36). Phone app; a matching desktop release is 0.7.0.

**Share linked documents with your partner**
- In a linked document's screen, turn on **Share with partner**. Your partner's Stack then shows it in search and the document list, marked **Shared by** their name for you. They can read the saved text and preview; they cannot change or delete your file.
- One-time set-up, together: open **Pair with partner** on both phones and scan each other's code once, in person. Then choose the shared folder once in Settings (Partner sharing folder on the phone that shares, Partner shared folder on the phone that receives). Filen Files' one-tap version of this comes with a later Filen Files release.
- Everything is encrypted before it leaves your phone. Making a new code stops future sharing under the old one but does not remove copies already stored in Filen.
- The code is a secret: anyone who photographs it could read what you share until you make a new one.

**Linked documents follow Filen**
- When a file is renamed, moved, trashed, restored, unshared or deleted in Filen Files, the linked document in Stack follows (with Filen Files 0.4.7 or later).
- A linked document shared from Filen shows a clear note if your partner could not open it because the file is not in Filen.

**Smaller things**
- Backup screens no longer mention computer commands; they point to Key Vault's own screens.
- Stack checks that the app answering as Filen Files really is Filen Files before using it.

**Installing**
- Tap **Update** in Stack (Home notice or Settings → Update check), or install `Stack-0.19.0.apk` as an update. It is signed with the same key as earlier versions. Make a backup first. The library format changes (older Stack versions cannot open a library this version has upgraded), so update every phone you use.

Checksums are in `SHA256SUMS`.
