Android **0.20.0** (versionCode 36 → 37). Phone app; a matching desktop release is 0.7.1.

**Set up with your partner**
- New on a phone with no documents: **I'm joining my partner** walks through four steps: install Filen Files and Ami Pro, sign in to Filen Files, scan your partner's code, and choose their shared folder. It is also in the Home menu.
- **Invite partner** (Home menu and Partner sharing) sends your partner a link that shows them what to install. The link holds no secret and nothing about your library.
- Filen Files' one-tap version of pairing is still off. For now: pair in person (scan each other's code), share the folder with your partner in Filen Files, and choose it in Stack (Settings, Partner shared folder). Your partner has to be your Filen contact first; accept the contact request in Filen's web app.

**Companion apps**
- One screen (Settings) installs and updates Filen Files and Ami Pro, with **Update all**. Stack checks each download (publisher, app, version) before Android asks you to confirm.

**After restoring a backup**
- Linked documents come back marked as restored. Open one once in Ami Pro and it is linked again. Stack no longer reports them as lost.

**Smaller things**
- Shorter wording across the app (about 115 messages).
- Backup encryption now starts with a passphrase and tells you to write down and keep the recovery key. Scanning a key from Key Vault is still there as the other choice. The restore prompt no longer names Key Vault.
- One name for the two folders in Settings: Partner sharing folder (what you share) and Partner shared folder (what your partner shares).
- Backup information is a short list with Learn more.

**Installing**
- Tap **Update** in Stack (Home notice or Settings → Update check), or install `Stack-0.20.0.apk` as an update. It is signed with the same key as earlier versions. Make a backup first. The library format changes (older Stack versions cannot open a library this version has upgraded), so update every phone you use.

Checksums are in `SHA256SUMS`.
