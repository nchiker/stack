Stack for Linux **0.7.1** (amd64 .deb). Goes with phone 0.20.0.

**New**
- **Add Ami Pro?** On first start, when Ami Pro is not installed, Stack offers to install it through the system's own installer (it asks for your password). It stays out of the way if Ami Pro is already installed, including a copy installed with Ami Pro's own install script in your home folder. "Not now" hides it.
- Starting Stack a second time brings the window you already have open to the front instead of showing an error.
- Stack remembers where your Filen folder is after you choose one document for Open in Ami Pro, so the other documents in it open without asking again (Settings has "Forget this folder").
- When you edit a linked document on this computer, Stack notices at start and when you return to the window, marks it "Changed on this computer", and uses the text from this computer's copy for search until your phone saves it again.
- Shorter wording across the app.

**Installing**
- Download the .deb from the start page and double-click it, then Install. It sets up its own updates, so later versions arrive with your other updates.
- The library moves to a newer format the first time you open this version (schema 8 to 9). Install it on every computer you use. A matching phone update is 0.20.0.
- Needs Ubuntu 24.04 or newer, or a distribution based on it (for example Linux Mint 22 or Pop!_OS 24.04).
